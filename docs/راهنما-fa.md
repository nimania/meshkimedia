# راهنمای مشکی مدیا (Meshki Media)

این راهنما برای **صاحب پروژه (نیما)** و هر کسی است که فارسی می‌خواند. مستندات فنی کامل (انگلیسی) برای برنامه‌نویس یا هوش مصنوعی در همین پوشه است؛
نقطهٔ شروع آن‌ها [`HANDOFF.md`](./HANDOFF.md) است.

- **سایت:** https://nimania.github.io/meshkimedia/
- **کد:** https://github.com/nimania/meshkimedia
- **مجوز کد:** MIT (داده‌ها متعلق به منابع‌شان است)

## سایت چه کار می‌کند؟

مرجع فارسیِ سریال‌های ترکی: ریتینگ روزانهٔ تیاک (Total / AB / ABC1)، صفحهٔ سریال، قسمت، بازیگر، کاراکتر و شبکه، تقویم پخش
(ساعت ترکیه، ایران و لس‌آنجلس)، خلاصهٔ قسمت‌ها، فراگمان‌ها، جستجو، و **اخبار** (از ۱۴۰۵/۰۷/۰۷ به بعد).

## اخبار چطور کار می‌کند؟

۱. هر بار که سایت ساخته می‌شود، ۸ فید خبری ترکیه (هریت، صباح، میلیت، هابرترک، سوزجو، تی‌آرتی، آناتولی، دیلی صباح) خوانده می‌شود.
۲. خبرهایی که دربارهٔ سریال‌ها/بازیگران/شبکه‌های سایت‌اند نگه داشته می‌شوند؛ موضوع‌های حساس (سلامت، اتهام جنایی و سوءاستفاده، مسائل جنسی، کودکان) کنار گذاشته می‌شوند.
۳. گزارش‌های تکراریِ چند رسانه دربارهٔ یک ماجرا **در یک خبر ادغام** می‌شوند.
۴. Gemini برای هر خبر عنوان فارسی، خلاصه، متن توضیحی (با کلمات خودش، نه ترجمهٔ خط‌به‌خط) و بخش «مقایسهٔ منابع» (مورد اتفاق / تفاوت روایت‌ها / تأییدنشده) می‌نویسد.
۵. هر خبر صفحهٔ خودش (`/haber/<شناسه>/`) را دارد، با تصویر، نشان (لوگو) رسانه‌های منتشرکننده که به مطلب اصلی لینک می‌شوند، سریال/بازیگر/شبکهٔ مرتبط و ریتینگ زندهٔ سریال.
۶. خبری که عنوان فارسی نداشته باشد در سایت **نمایش داده نمی‌شود**.

بیوگرافی بازیگران از ویکی‌پدیا (ابتدا فارسی، وگرنه ترکی/انگلیسی با ترجمهٔ ماشینیِ برچسب‌دار) با نام منبع و مجوز CC BY-SA می‌آید.

## کارهایی که فقط خودت می‌توانی بکنی

- **کلید Gemini** (انجام شده): aistudio.google.com/apikey ← Create API key ← در گیت‌هاب: Settings ← Secrets and variables ← Actions ← New repository secret با نام دقیق `AI_API_KEY`.
  برای ظرفیت بیشتر می‌توان چند کلید را با ویرگول در همین Secret گذاشت.
- **ربات تلگرام** (برنامه‌ریزی‌شده): ساخت ربات با @BotFather، مدیر کردنش در کانال، و Secretهای `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHANNEL_ID`.
- **لوگوی واقعی رسانه‌ها** (اختیاری): فایل‌هایی مثل `hurriyet-kelebek.png` را در `github-pages/images/outlets/` آپلود کن.
- هیچ‌وقت کلید یا رمز را در چت، فایل یا لاگ نگذار.

## اگر خبرها نیامدند؟

۱. برو به github.com/nimania/meshkimedia/actions ← «Publish Meshki Media to GitHub Pages» ← آخرین اجرا ← **Summary**.
۲. بخش «اخبار» می‌گوید چند خبر ساخته شد؛ اگر خطا بود (مثلاً «مدل قدیمی شده» یا «مدل شلوغ است») همان متن را به دستیارت نشان بده.
۳. اگر اجرا گیر کرد: Cancel workflow و بعد Run workflow.
راهنمای کامل عیب‌یابی: [`OPERATIONS.md`](./OPERATIONS.md) بخش ۶.

## زمان‌بندی

سایت روزی حدود ۶ تا ۷ بار خودکار ساخته می‌شود (۱۰:۴۷، ۱۱:۴۷ و ۱۲:۴۷ به وقت تهران، و هر ۶ ساعت) و هر بار هم که فایلی در مخزن عوض شود. اخبار هم با همین ساخت تازه می‌شوند.

## سیاست صداقت داده

مشکی مدیا هیچ عددی از خودش نمی‌سازد. تیاک فقط جدول Total را با عدد دقیق منتشر می‌کند؛ برای AB و ABC1 رتبه نشان داده می‌شود مگر رقم را از منبع معتبر و بازبینی‌شده داشته باشیم (با ذکر منبع). متن کامل مقاله‌ها و عکس‌های دیگران کپی نمی‌شود؛ عکس‌ها از منبع اصلی لینک می‌شوند.

## چطور یک سریال اضافه کنم؟

در `github-pages/data/series.json` یک ورودی اضافه کن (حداقل `slug`، `titleFa`، `titleTr`، `ratingKey`، `network`، `status`، `kind`، `day`، `dayIndex`، `airing`، `seasons`)،
اگر شبکهٔ جدید است در `networks.json` اضافه‌اش کن و بعد از انتشار، سایت خودش صفحه‌ها را می‌سازد. جزئیات: [`DATA-MODEL.md`](./DATA-MODEL.md).
(در عمل معمولاً دستیارت این کار را برایت انجام می‌دهد.)

## اجرای محلی (برای برنامه‌نویس)

```bash
git clone https://github.com/nimania/meshkimedia.git && cd meshkimedia
node automation/build-site.mjs
cd github-pages && python3 -m http.server 8080     # http://localhost:8080/
```
