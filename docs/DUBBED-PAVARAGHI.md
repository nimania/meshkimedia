# Persian dubbed series / پاورقی مشکی‌مدیا

This section is generated by `automation/build-site.mjs` into `github-pages/duble/` and indexed in sitemap/search.

## Workflow
1. Confirm the title and original Turkish episode number from a verifiable source.
2. Record the exact GEM/MBC Persia broadcast and Persian episode mapping only when verified.
3. Draft a scene-by-scene original Persian recap using actual video, subtitles or checked transcript. Do not invent dialogue or scenes.
4. Review facts, naming consistency, copyright issues and episode boundaries.
5. Record your own narration and publish it manually to YouTube.
6. Set the entry's `youtubeId` to the 11-character YouTube video ID. Alternatively set `audioUrl` to a licensed hosted MP3.
7. Change `status` to `published`; drafts never appear publicly.

## Data
Edit `github-pages/data/dubbed.json`:
```json
{
  "version": 1,
  "networks": [{"id":"gem","name":"GEM TV","verified":false}],
  "series": [{
    "slug":"example-series", "titleFa":"عنوان فارسی", "titleTr":"Turkish Title",
    "description":"معرفی کوتاه تاییدشده", "hero":"",
    "originalSeriesSlug":"existing-series-slug-if-any",
    "broadcasts":[{"network":"gem","channel":"GEM SERIES","verified":true,"sourceUrl":"https://..."}],
    "entries":[{
      "slug":"ep-1-fa-1","title":"پاورقی قسمت ۱", "originalEpisode":1,
      "persianEpisode":1, "part":1, "parts":4,
      "status":"published", "publishedAt":"2026-10-09",
      "paragraphs":["متن مستقل و تاییدشده...", "پاراگراف بعدی..."],
      "youtubeId":"", "audioUrl":"", "sourceUrl":"https://..."
    }]
  }]
}
```
Numbers and broadcast mappings must be source-verified; do not mechanically divide a Turkish episode into four. The `paragraphs` are complete original prose and must not be copied subtitles. External media must have publishing rights.

Do not publish placeholder recaps. The empty initial catalog intentionally only publishes the landing page.
